
# QA Automation Engineer – 45 Days of Upskilling 🚀

## About This Repository
This repository documents my 45-day journey towards becoming a skilled QA Automation Engineer / SDET.

I will focus on developing practical skills in Java, Selenium WebDriver, TestNG, API Testing, Framework Development, Git, CI/CD and Generative AI for QA.

## My Learning Goals

- Strengthen Java programming fundamentals.
- Understand OOP concepts and SOLID principles.
- Develop browser automation using Selenium WebDriver.
- Build maintainable automation frameworks using TestNG and Maven.
- Learn API testing using Postman and REST Assured.
- Understand Git, GitHub and version control workflows.
- Implement CI/CD pipelines using Jenkins or GitHub Actions.
- Explore Generative AI applications in software testing.
- Develop a real-world automation testing project.
- Prepare for QA Automation Engineer / SDET interviews.
